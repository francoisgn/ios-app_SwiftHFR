**Problem.** The colour palette writes `[ff0000]x[/ff0000]`, not the tag HFR documents; how HFR renders it is not captured.

**Cause.** `ReplyFormattingTarget.rawTag` returns the bare hex, as legacy does (`HFRswift/Swift/AnswerView.swift:35` on `origin/master`). HFR's tag is `[#rrggbb]` (capture `R41a`, HFR-PROTOCOL §6c).

**Change.** `rawTag` adds the `#`. Only that case changes; the palette's `hex` values and the other tags stay. CHANGELOG-LEGACY row.

**Tests.** `aColourTagStartsWithItsHash` expects `[#ff0000]x[/#ff0000]`; it fails on the bare hex.
