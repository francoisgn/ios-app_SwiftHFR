**Problem.** Réglages › Général carried an « Images externes » picker (Jamais / Wi-Fi uniquement / Toujours, default Wi-Fi). Legacy has no such setting: it forces `display_images = "yes"` (`HFRplusAppDelegate.m:117-118` @ 87fe0d1c).

**Change** (operator decisions of 2026-11-14 on #902).
- The picker leaves the main Réglages and `GeneralSettingsModel.imageLoading` is removed.
- Images always load, cellular included: `ReaderSettings.autoLoad(store:)` returns `.always` unless the experimental choice is on. The `display_images` default is now `yes`.
- The choice moves to Réglages › Expérimental › « Chargement des images » (`imageLoadingChoice`, now listed): once the switch is on, a Toujours / Wi-Fi uniquement / Jamais (au toucher) picker shows under it and writes `display_images`. Code in `App/SwiftHFR/Experimental/ImageLoadingChoice/`, marked `// EXPERIMENTAL(imageLoadingChoice, #902)`.
- Old values: the key is kept; a value an earlier build stored (`no`, `wifi`) is ignored while the option is off (images show after the update) and becomes the picker's value if the option is switched on. No migration, no crash.
- Policy C privacy parts (cookie-less client, no private hosts) untouched; `ImageDecision` unchanged.
- ADR 0013 row of `display_images` updated.

**Tests** (fail without the change): `theImageModeIsAlwaysUnlessTheExperimentalChoiceIsOn` (stored `never` + option off → images auto-load on cellular; option on → the stored mode applies), `theModelNoLongerWritesDisplayImages`, `privateHostsStayBlockedWhateverTheSetting` (option on, every mode), `ImageAutoLoad(setting: nil) == .always`, `SettingKey.displayImages` default `.always` (HFRKit: `swift test --filter HFRStorageTests` green here, 515 tests); the Experimental tests now expect the option listed under « Chargement des images ». SwiftLint `--strict` clean on the touched files. App tests not run here (Linux).

**Device-check points**

- Cellular (Network Link Conditioner / Wi-Fi off): third-party images load without a tap.
- Update from a build with « Jamais » stored: images show.
- Réglages › Expérimental › Chargement des images: switch on shows the picker (default Toujours); Jamais puts placeholders back, Wi-Fi uniquement loads only on Wi-Fi; switch off returns to always.
