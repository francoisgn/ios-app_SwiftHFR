**Problem.** No engine flow to vote in a poll. Under LOT-037's rule HFR's vote confirmation `W42` ("Votre vote a bien été pris en compte !", no "avec succès") is `unrecognized`, so a vote could never be confirmed.

**Cause / legacy.** `PollData.swift:47-100` @ 2440d79 posted the hidden fields from an unordered dictionary, without `sondage_submit`, and called any page without a `.hop` link (or without any `.hop`) a success.

**Change.**
- `HopResponseParser.Context.pollVote`: success = link-less `.hop` whose whole text is the vote sentence + forum refresh. The vote sentence confirms nothing under `.write`, and "avec succès" confirms nothing under `.pollVote`.
- `PollVoteFlow` (HFRClient): checks the `Poll` from `PollParser` (only the captured form shape; otherwise `notVotable` / `unsupportedPoll` / `invalidChoice`, with nothing sent), then a LOT-044 session check (as flags, #314), then one POST with exactly W42's body (document order, the session's token twice, `reponse`, `sondage_submit=Voter`). `W43`/`W44` → `alreadyVoted`; after-send failures → `unconfirmed`.
- Docs: spec `docs/lots/LOT-054-poll-vote.md`, HFR-PROTOCOL §3 row + §6c LOT-054, CHANGELOG-LEGACY #56.

Scope is limited to the vote. No `HFRModels` type changed, and `PollParser` is untouched.

**Tests** (`swift test`: 1300 tests pass; `swiftlint --strict` clean)
- `PollVoteFlowTests`: the R83 vote is byte for byte W42's request body, and W42-W44 bodies match. R32b body. W42 confirmed (topic, choice, refresh). W43/W44 already voted. Other answers (W17b, W17c, W20a, W30, a page without `.hop`, redirect, transport, HTTP 500) are never a success. Missing token, results polls, invalid choices and 9 unsupported form variants send nothing.
- `PollVoteSessionGateTests`: unconfirmed or failed check, cancellation, public entry point gated (loopback-only `HFRSession`), and a real `SessionRefreshFlow` probe.
- `HopResponsePollVoteTests`: corpus sweeps (only W42 succeeds under `.pollVote`; nothing under `.alertPrepare`), W43/W44 refusals, write confirmations not a vote, derived negative shapes. With the `.pollVote` rule reverted, 5 of these tests fail.
