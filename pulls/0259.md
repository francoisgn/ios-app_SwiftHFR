**Security Blast Radius**
- _inferred_ — The demonstrated exposure is private content from an ingested MPStorage capture reaching the published fixture corpus and its readers. **Security Findings and Attack Paths**
- _observed_ — A document such as {"blacklist":{"list":["UnseenMember"],"list":[]}} loses the first list in the primary parser. The independent hook records keys and direct string-valued object members, but not scalars inside that overwritten list; its later traversal sees only the surviving empty list. If the name is neither configured nor discovered elsewhere and matches no other leak pattern, residual redaction and findings do not supply the missing check, while publication retains the original duplicate-key bytes.
- _inferred_ — Markup-mode validation also omits tags and attributes from the representation it checks, although the preservation path retains source markup subject to general redaction. This leaves a conditional channel for otherwise undiscovered private attribute content. Whether real captured documents can carry such content remains unresolved; browser execution is not established.

**Trust Boundaries and Controls**
- _observed_ — The strongest countercontrols are independent header/title recognition, refusal of ordinary unknown values and surviving bare list elements, configured identity and secret redaction, and a final findings gate before publication. The verifier also catches direct duplicate string values. None of these establishes inspection of scalars in discarded duplicate-key lists.

**Resilience and Maintainability Implications**
- _observed_ — Publication validates in memory before writing and catches anonymization errors as refusals. Alias state is reset per call, while page and metadata share the current publication's aliases. Repetition still reuses the same acceptance policy, so retrying a document does not correct a validation blind spot.

**Hardening Proposals**
- _proposed_ — Make preservation validation cover the complete released representation: reject duplicate keys before values are discarded, and explicitly constrain retained markup rather than treating tag-stripped JSON as sufficient proof. Preserve the independent verification gate.
