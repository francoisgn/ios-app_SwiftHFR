**Problem.** LOT-067's importer (#703) tested the pseudo-list and draft formats on samples built from the legacy shapes, not on bytes the legacy app writes.

**How the samples were produced.** The method of #347: real legacy code on synthetic data, from an XCTest in the legacy test host on an iOS 27.0 simulator with no account. The legacy revision is `origin/master` `21173e77`, not the oracle's `2440d79`, because `reply_active_drafts_by_topic_v1` does not exist at `2440d79`. The exporter is `tooling/legacy-oracle/stores-709-master.patch` (local worktree only, never pushed to the legacy app). Provenance and storage location of each file are in the MANIFEST section "Legacy on-device samples", block **#709**.
- `BlackList.m` (save, load, add, remove) writes `blackListDico.plist` and `whiteList.plist` in Documents (XML plists). `MultisManager`'s current-account readers answer a fake account, since the test host has none, and `mpstorage_active` is off.
- `ReplyDraftStore.saveActiveText` writes `reply_active_drafts_by_topic_v1`: JSON `Data` in UserDefaults, with the legacy code's own `Date()`.
- `brouillon`: see the findings.

**Findings.**
- **The `brouillon` writer is not in the Swift app.** `AddMessageViewController.m` is built into the `SuperHFRplus` target only. Its one line (`AddMessageViewController.m:483`, `setObject:forKey:@"brouillon"`) is transliterated, as #347 did for the ObjC favourites screen.
- **The v0 `blackList.plist` is synthetic input**: no code at `21173e77` writes it. The real migration (`BlackList.m:186-190`) writes the dictionary over the v0 path and then deletes it, so **no list file is left on disk until the next save** (`lists-v0-after-load-files.txt` is empty). The importer reads the v0 file when it is present, so an install that never saved after migrating has lost its list. This is recorded in the LOT-067 spec.
- Emptied lists stay as empty arrays per account. The last active-draft removal deletes the key. Active drafts are capped at 50 topics, newest first, with keys in `JSONEncoder` order.

**What changed.**
- 20 samples in `tooling/legacy-oracle/samples/legacy-stores/` and the exporter patch.
- `LegacyListsDraftsSamplesTests`: 4 tests, which decode every sample through `LegacyFormats` (`blocklists`, `pseudoList`, `brouillon`, `activeDrafts`). They pass locally with `swift test` and fail without the samples.
- MANIFEST, the LOT-067 spec ("Captured", the test-input line) and the legacy-oracle README.

**Leak check.** An independent Sonnet sub-agent found only synthetic `fake*` values: no paths, UUIDs or credentials, and the patch is clean.
