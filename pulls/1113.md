1. **Medium**, `App/SwiftHFRTests/Offline/OfflineSaveBannerGlassTests.swift:33-50`: the test does not read pixels as RGB.
   - **What happens:** `UIGraphicsImageRenderer` uses its default format, which on this simulator gives a 64 bpp image with 16-bit components in Display P3. `pixel()` then takes the first 3 **bytes** of each 8-byte pixel. That is red's low byte, red's high byte and green's low byte, not R, G and B. The page "red" sampled that way is `[191,235,224]` in light and `[31,236,16]` in dark.
   - **Failing scenario:** I decoded `after/dark.png` correctly (sRGB, 8-bit). Under the glass the strip differs from the page by only 7 to 9 per channel, and 0 of 2700 samples pass the intended `> 12`. Read as raw bytes, all 2700 pass. So the dark case is green only because of the byte misreading. With an 8-bit format (another runner, or another default range), it goes red with the fix in place. The 12-per-channel threshold measures nothing.
   - **Fix:** set `format.preferredRange = .standard` and `format.scale = 1`, as `ListDensityMarginsTests.swift:249` does, or draw into an 8-bit `CGContext` (`AppThemeTests.swift:98`). Recalibrate the threshold from the dark render (about 7 to 9 over flat red), or use a page colour where dark glass changes more. Replace the fixed 500 ms sleep with polling (the #704 lesson on blank renders).
2. **Low**, `App/SwiftHFR/Offline/ReaderOfflineSave.swift:90`: the `.capsule` shape doesn't fit text that wraps.
   - **Scenario:** at accessibility text sizes, `.failed(message, saved)` text such as « Vérifiez votre connexion puis réessayez. (2 pages enregistrées hors ligne) » wraps. The capsule's radius is half its height, so the corners of the first and last lines fall outside the glass.
   - **Fix:** the sibling top strip in a `safeAreaBar`, `FilteredPostsBanner` (`FilteredPostsView.swift:75`), uses `.rect(cornerRadius: 10)`. Use that, or `ConcentricRectangle`.
3. **Detail**, PR body: `Closes #588` is acceptable, because the change is complete for a banner nobody can reach today. But nothing will remind anyone to check it over real messages. Add that check to #846's acceptance criteria and say so on the PR.

The legacy claim holds: at `87fe0d1c` there is no « hors ligne » string, and the only offline Swift code is `OfflineStorageTopicPageRenderer` (`Common.swift:2181`).
