**Problem.** Today's dense rows (dot and flag icons, three-line MP block) are gone from the default build (#962, #964) and have no way back; the operator's 2026-11-16 decision keeps them behind Réglages › Expérimental, with new rules (#905 C–F, #973).

**Cause.** `TopicRowStyle.current` was hard-wired to `.legacy`, `MessageRowView.usesDenseRows` to `false`, and the option (`flagIconRows`) was hidden.

**Change.**
- Option renamed `flagIconRows` → `denseRows` (« Lignes denses », device key `experimental.denseRows`, off by default, never shipped listed, so no stored value to migrate); now listed. Folder `Experimental/DenseRows/`.
- `DenseRowFormat`: one pure formatter for both dense rows. Topic: `⚑ lue / total · last poster · age` (last poster instead of starter, no reply count, no « il y a »: « 14 minutes », « 2 semaines »). MP: interlocutor or `⚑ page / pages` (never « Interlocuteurs multiples », no reply count), last poster, `6 min` / `2 h` / date.
- One line, ended by « … » (`lineLimit(1)` + tail truncation). **Deliberate departure from « never wraps » (#905 E):** the limit is lifted at accessibility text sizes, where a cut line cannot be read (HIG). Say if the operator wants it never lifted.
- Section titles bold in the dense view only (F); with the option off no weight modifier is added.
- `TopicRowView`, `MessageRowView`, `TopicListView` read the option through `TopicRowStyle.current(_:)`, `DenseRowFormat.isOn(_:)` and `DenseRowFormat.titleWeight(_:)`; `DenseTopicRowView` moved to `Experimental/DenseRows/`; the old three-line MP meta block and `ListDensity.mergesMetaLines` are removed (dead). Markers `// EXPERIMENTAL(denseRows, #905)`.
- The flag row tint (`rowPill`) is unchanged in both styles: the dense row shows the icon and the tint, as today's rows did.
- Default build unchanged: option off (or no settings in the environment) = legacy rows, default section titles.

**Tests** (`DenseRowsTests`, Swift Testing): switch on/off → row style, MP and section-title switch points; C/D/E topic line, units of the age, partial topics; MP A–D group and one-to-one; line limit; bold weight on, none off. They reference `DenseRowFormat` / `denseRows`, so they fail without the change (app tests cannot run on Linux; compile-check builds them). HFRStorage key tests updated and run on Linux (30 passed). SwiftLint clean locally on the changed files; CI SwiftLint is red on `dev-swift` itself (`MessageListModel.swift` 417 lines, from LOT-140 #994, not touched here).

**Device check** (operator's general review): dense rows with the option on and off, no reload on switch (reads the `@Observable` settings), truncation « … » on a narrow iPhone.
