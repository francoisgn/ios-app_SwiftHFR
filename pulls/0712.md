### Findings, by severity

**1. D2 videos cannot be played by click or tap (major, front).** `web/style.css:56` stretches the invisible radio input over the whole `.option` (`position:absolute; inset:0; width/height:100%`). `app.js:216-222` puts the details `<ul>` and the visual `<figure>`s inside that same `.option`. They are not positioned, so the input sits on top of them. I checked in a browser with `elementFromPoint` at the centre of each `<video>` and `<img>` on the D2 screen: it returns `INPUT#D2-tableau_de_bord` and `INPUT#D2-cote_a_cote`. A tap on the video controls selects the radio instead of playing the video, which breaks the purpose of D2's visuals for people without the device.
*Fix*: wrap only `input` and `label` in a positioned box (for example `.option > .choix { position: relative }` with the input inset inside it), and keep the details and figures outside it. Or add `.option .visuel, .option .details { position: relative; z-index: 1; }`. Also add a manual check "play a D2 video by tap" to the §14 list.

**2. Draft lost after a version-mismatch 409, although the message says it is kept (minor).** `app.js:356` says « rechargez la page. Vos réponses sont gardées ». But the draft key contains the version (`logique.js:169`), and `lireBrouillon` rejects any other version (`logique.js:181`). After the reload, the new key is empty and the answers are gone.
*Fix*: either change the message, or, when no draft exists for the current version, salvage the newest `ux-survey:*:brouillon`, keep only the answers whose IDs and codes still exist, then delete the old keys. This only matters if the content is corrected mid-survey, but that is exactly when the message shows.

**3. Per-address limit is bypassable over IPv6 (minor, open point 5).** `stockage.EmpreinteIP(cle, s.IPClient(r))` (`api.go:116`) and the rate limiter (`middleware.go:129`) key on the full address. A phone with IPv6 privacy addresses rotates inside its /64 at will, so `UX_MAX_PAR_IP=3` and 10 POST/h do not hold. A /64 is about what one IPv4 NAT is (one household or line).
*Fix*: in `IPClient`, or in a small helper used by both, map IPv6 to `netip.PrefixFrom(a, 64).Masked().String()`, plus one test.

**4. Empty submissions are stored and counted (minor, PO call).** `{"reponses":{}}` returns 201 and inserts a row (checked by hand), which counts towards `total` and the global threshold of 10. That is consistent with "everything is optional" and the per-question threshold prevents any small-cell leak. Still, it adds noise and lets 4 addresses unlock "disponible". Suggestion: when `Donnees` is empty and there is no pseudo, answer 201 as for the honeypot but store nothing (log reason `vide`). If you keep the current behaviour, write the choice down in the spec.

**5. Weak or tautological tests and gaps against §14 (minor).**
- `internal/exporter/exporter_test.go:106`: `slices.IsSorted([]string{rows[1][0]})` sorts a one-element slice, so it is always true. Either assert sorting over several rows or delete it.
- `internal/web/web_test.go:239-243` (first loop of `TestDebit`): sends 11 requests and checks nothing (`_ = rec` at :279). `:183/:189`: the `cfgSans` variable is unused. `internal/stats/stats_test.go:71/85`: `_ = m` and `repetees(0, nil)` are leftovers.
- Concordance: the I1 `lien` text is not compared (see the mutation result above). Compare the second «…» of the I1 `Aide` line with `qu.Lien`.
- Test 24 asks for "absente des exports `analyse` et `agregats`". The exclusion is only checked through `Base.Reponses()`. `cmd/ux-survey` has no test at all: no check of the export file naming and 0600 mode, of `agregatsCourants` reading the snapshot after erasure, of R5 enforced by `charger()` for every command, or of `effacer` refused through the CLI. A thin `commandes_test.go` that drives `lancer()` with a temp data directory and `t.Setenv` would cover all of these.
- No concurrency test for the double click or network retry: two goroutines POST the same token, and exactly one 201 and one 409 should come back. The design (one connection, `INSERT … ON CONFLICT` first) is right, so the test is cheap insurance under `-race`.
- `statique_test.go:48`: the CNIL allow-list uses `strings.HasPrefix(u, "https://www.cnil.fr")`, which also accepts `https://www.cnil.fr.example.net`. Use an exact match.

**6. Dead code and over-engineering for a two-week survey (minor).**
- `internal/stockage/base.go:95-100`: an `ALTER TABLE … ADD COLUMN limitee` "migration", matched on the error string, for a database that was never deployed. `CREATE TABLE` already has the column, so remove it.
- `internal/reponse/valider.go:209-210` `CodeEnMinuscules`: unused. `stockage.ToutesLesReponses`: used only by tests. `contenu.Ecran.Melange` and `"melange": true`: never read (`app.js:129` hardcodes `ecran.id === 'cartes'`). Either drive the shuffle from the flag or drop it.
- `web.Serveur.Instantane` (`serveur.go:200`) duplicates the closure in `commandeEffacer`; keep one. `api.go:158` `bytesReader` is a one-line wrapper. `ecriture.go:83` returns `sql.ErrConnDone` for an ID collision, which is misleading; use a dedicated error.
- `app.js:424`: `envoyeesSession` is always `{}` when the page loads closed, so the closed screen never marks "Votre réponse". Drop it.

**7. Invisible bidi characters in Go source (minor, maintainability).** `internal/reponse/texte.go:28` writes U+202A…U+202E and U+2066…U+2069 as literal characters (`reponse_test.go:108` has a literal U+202E too). GitHub flags them as hidden Unicode, and reviewers cannot see them.
*Fix*: use `'‪'` and similar escapes. While there, also strip U+200E, U+200F and U+061C (LRM, RLM, ALM).

**8. R5 stored with second precision (minor).** `api.go:118` stores `Fermeture.Format(time.RFC3339)`, which drops fractional seconds. If `UX_FERMETURE` carries any, the next start sees the configured date as *later* than the stored one and refuses to start.
*Fix*: truncate to the second in `ChargerConfig`, or store with `RFC3339Nano`.

**9. `pseudo --chercher` does not normalise its argument (nit-level bug).** `ecriture.go:179` compares the stored pseudo, which is NFC-normalised with newlines turned into spaces, against the raw query. Pass the query through `reponse.NormaliserTexte(q, true)` first. Pasted NFD text will otherwise miss.
