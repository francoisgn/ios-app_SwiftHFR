**Problem.** The merge criteria existed only in `.github/rulesets/dev-swift.json` and `scripts/configure-repo.sh`. Neither contributors nor agents could read them anywhere. `CONTRIBUTING.md` also said that issue forms set labels automatically, which is false on this repository: GitHub only reads forms from `master`.

**What changed**
- **`CONTRIBUTING.md`**
  - The path from task to PR, with two kinds of claim: a lot in `LOTS.md`, anything else through an assigned issue.
  - **Merge criteria**: the 7 required checks and what each one verifies, 0 conflict, **every conversation resolved** (a reply alone does not unblock the merge), approval once ADR 0011 is accepted, squash.
  - The two diagrams, and links to the tool documentation.
  - How to open an issue by hand while the forms do not show.
- **`README.md`**: the Contributing section points to the merge criteria and gives the **prompt to start an agent**.
- **`CLAUDE.md`**: Claude's guardrails, on top of the imported AGENTS.md: `dev-swift` only, no direct push, one claimed task, no guessing about HFR, no secrets, confirmation before consequential actions, merge criteria. AGENTS.md now says what CLAUDE.md holds.
- **`docs/assets/`**: `ci-pipeline.png`, `work-process.png` and their Excalidraw sources.

**Checks**: markdownlint (0 errors), `check-lot-deps.py` (0 violations). Docs only.
