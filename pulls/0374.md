**What changed.**
- `docs/migration/GAP-LEGACY-VS-SWIFT.md`: 155 rows with stable ids (`GAP-001`…), one table per area (navigation, lists, reader, composer, MPs, search, settings and appearance, accounts, offline and sync, notifications, accessibility, large and foldable screens). Columns: feature, legacy behaviour, legacy `file:line` at `2440d79`, SwiftHFR final, LOT/FEAT, gap type, source of the change. Counts per type, 12 convergence decisions, open questions, and the assumptions of the image (Duo sizes).
- `docs/assets/gap-legacy-vs-swift-1-iphone.png` (iPhone 16, 18 Pro Max portrait and landscape) and `-2-duo.png` (Duo closed, open landscape, open portrait): mock-ups of the main reading screen, legacy left, SwiftHFR right, rendered at @3x. Split in two because one image would be over 15 000 px tall.
- `docs/assets/gap/` holds the HTML source and `render.js` (Playwright) to re-render them.
- README documentation map: one row for the report.

**Why this wide.** Docs only; no spec, lot or code is changed. Disagreements found between specs (e.g. LOT-084 vs LOT-101, `master` vs `2440d79` citations in LOT-119/170) are listed as convergence notes, not fixed here.
