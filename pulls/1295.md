**Problem.** Below 100 % the reader's text goes under 11 px (HIG minimum; the lists have the floor since #1157/#1236). At 70 % and the default Dynamic Type size, measured in the real reader: body 10.5 px, date 10.1, quote header and signature 8.9, "Nouveau" badge 8.3, quoted bubble 9.1, trailer 10.1.

**Cause.** `ReaderWebController+Scripts.swift:88` only sets `--text-scale`; `reader.css` multiplies every size by it (`body`, `--content-em`, and `em` ratios) with no floor.

**Change.** `reader.css`: one variable per real nesting ratio, each `max(scaled, min(size at 100 %, 11px))`, the rule of `TextScale.pointSize` (operator decision on #1237): `--fs-body`, `--fs-content`, `--fs-85`, `--fs-765`, `--fs-70`, `--fs-85-content`, `--fs-7225-content` (code header, signature image button and link), `--fs-614-content` (code header in a signature), and for sub and sup a rule reading the context's size at 100 % (`--context-100` on `.content` and `.signature`, `--code-100` on code blocks), never the possibly floored parent. The video button and pill use `--fs-85` (article children). 100 % and above are unchanged; a text already under 11 px at 100 % (code header 10.84, signature image items) keeps that size when shrunk, never smaller or bigger. Floored per element because an `em` chain would floor only the parent. `ReaderTextScaleTests` uses 80 % (its 70 % factor check no longer holds). Legacy never goes below 100 % (`Common.swift:314-322` @ 87fe0d1c): the range is SwiftHFR's, no ledger entry.

**Acceptance (reworded as on #1237).** At 70 %, every reader text computes to at least `min(its size at 100 %, 11 px)` and at most its size at 100 %; 100 % and above unchanged.

**Tests.** App-hosted WebKit suite `ReaderTextFloorWebTests` (iPhone Duo, iOS 27.2 simulator), 19 elements: content, date, quote header, bubble, badge, signature, trailer, video button and card, code header, signature image button and link, sub, sup, sub in a code block, sub in the signature, code header in a signature. Each is measured at 70, 100 and 130 % at the default root size and at 14 px (xSmall Dynamic Type, set on the root since the host does not follow it).
