LOT-051 inputs (capture work, not a lot). This is partial for #304 and #305: their criterion "LOT-051 tests read the capture" is left to #314, which moves LOT-051 onto these captures.

**Problem.** LOT-051 reports every favourites-list removal as `unconfirmed` because the `manageaction.php` delflags answer had never been captured. The answers of `delflag.php` with `owntopic=0` and `owntopic=1`, of a repeated `delflag` and of a logged-out `addflag` were unknown too.

**What was captured.** Run 6, on 2026-10-28, approved by the operator that day. It used user2 only: 13 flag writes on three public cat 13 topics, at least 65 s apart, and one `addflag` GET without cookies.
- `forum1f.php?owntopic=0..3` was read before the first write and after the last one. Both reads show the same topics, the same flag kinds and the same positions, so the state was restored.
- No flood, refusal or captcha.

**Findings** (`docs/HFR-PROTOCOL.md` §6c, LOT-051 subsection):
- **List removal.** The browser body of `form1` answers "Favoris supprimés avec succès" with one or several rows (`P03h`, `P03l`). Legacy's body (no `owntopic`, marker at index 1) answers "Drapeaux effacés avec succès" with a refresh to `/` (`P03j`). Both removed the topic and its read flag.
- **delflag.** It answers "Drapeau effacé avec succès" for `owntopic` 0, 1 and 3, and also when sent again on a topic with no flag (`P03o` is byte-identical to `P03n`). `owntopic` only sets the refresh.
- **addflag logged out.** It answers the same bytes as the logged-in success `P03a` (`P03q`), so the sentence does not prove the write. This is #314.
- **Topic page.** The flag link of a favourite uses `favorisn.gif`; a topic that was only read uses `flagn0.gif` (`P03m` vs `R21`).

**Changed.**
- Corpus `P03g`–`P03q`, with their `MANIFEST.md` rows and a Run 6 note.
- LOT-002 oracles for the three favourites lists and a LOT-003 oracle for `P03m`.
- `corpus.json` and the P03 row of the capture checklist.

- The corpus sweep in `HopResponseParserTests` lists the new successes, `P03q` included, with a comment explaining why.
