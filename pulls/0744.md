### Problem
The Catégories list was collapsible `.sidebar` sections with no icon, no « N sous-forums », and no Tous / Favoris / Suivis / Lus filter (GAP-020..023). A category title in Favoris did not open the category.

### Cause
LOT-082 shipped sections instead of the legacy flat list; the filter and the icons were "not planned".

### Change
- Catégories: flat inset-grouped list (#427, #572), one row per category: 28 pt template icon (legacy images copied unchanged from `87fe0d1c`, credit in CREDITS.md), title, « N sous-forums » (from what the home parser already gives).
- Topic list of a category: « Sous-forum » menu (legacy picker) and the segmented Tous / Favoris / Suivis / Lus control (`TopicFlagFilterPicker`, one reusable component, #593 reuses it elsewhere). Persisted under the legacy key `HFRswiftGlobalTopicListFlag` (`SettingKey.topicListFlag`, device-only, ADR 0013 row added), mapped to `owntopic` as legacy (Favoris 3, Suivis 1, Lus 2).
- Favoris: a section title with a category id opens that category on the Favoris filter (`owntopic=3`), whatever the Favoris tab's mode, as legacy (`Favorites.swift:357` @ 87fe0d1c; operator decision 2026-11-10). Compact width pushes it on the Favoris stack; regular-width iPad switches the content column to Catégories (`MainWindow.swift:1955-1962`, `2221-2232`). A section without category id opens nothing.
- Logged out: only Favoris, Suivis and Lus are disabled, « Tous » stays usable, legacy's note is shown (`MainWindow.swift:683-705`). The sign-in is read inside the load, and a filter chosen while page 1 loads reloads with it.
- Legacy pointers `@ 87fe0d1c` in the touched files.

Deliberate differences left, recorded in the ledger: (1) the filter is disabled on a sub-forum (no `subcat` id on the home links; legacy silently lost the sub-forum, `ObjCForumTopicsLoaderWorker.m:36-89`); (2) logged out, the stored choice is kept (the control reads « Tous »); (3) « 1 sous-forum » in the singular.

Not fixed here: #647 (iPad flag-tinted rows in the topic column: this PR does not touch that list's style).

- `HFRStorageTests`: `TopicListFlagSettingTests` (key, defaults, mapping to `owntopic`, legacy integer write); catalogue and scope matrix tests updated. Written first; shown failing (`SettingKey.topicListFlag` missing) before the key was added.
