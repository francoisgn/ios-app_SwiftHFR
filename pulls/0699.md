Tests-only PR. Finding by Bybifok (moust4ki): legacy refresh reloaded page 1 (legacy fix `246a9c7`).

**Problem.** Check that SwiftHFR does not reload page 1 on refresh.

**Cause.** The bug does not exist: `TopicListModel.refresh()`, `MessageListModel.refresh()` (`load(page: currentPage)`) and `TopicReaderModel.refresh()` (reloads `shown`) all reload the page on screen. Already covered by `TopicListModelTests.refreshReloadsTheCurrentPageNotPageOne`, `.aSubforumPagesThroughItsOwnLinkAndRefreshesTheCurrentPage`, `MessageListModelTests.pagingMovesByOneAndRefreshReloadsThePageOnScreen`, `TopicReaderModelTests.refreshReloadsThePageOnScreenAndKeepsItWhileLoading` (reader opened directly on page 3).

**Change.** One missing path: the reader refreshed after the member paged (`goToPage`), where the page on screen differs from the page first opened. New test `TopicReaderModelTests.refreshAfterPagingReloadsThePagedToPageNotTheFirstOne` (requests `[1, 4, 4]`; a refresh reusing the opened page would give `[1, 4, 1]`). No app code touched.
