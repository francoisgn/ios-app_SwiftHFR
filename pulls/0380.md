## What and why
**Problem.** Directive H asks to separate two kinds of UI change:
- (a) **porting ezzz's legacy Swift layer**: the same UX, technical changes only;
- (b) **UX evolutions**.

So far the specs mixed both. Some (b) items already ship by default in merged code: Catégories sections, the topic row, the message header, the page bar, the tab bar kept in the reader, and the composer swipe-down.

**Changes.**
- `docs/migration/GAP-LEGACY-VS-SWIFT.md`:
  - an **H.1 column** on all 155 rows (`a`, `a·master`, `b·needed`, `b·operator`, `b`, `—`);
  - a **Convergence classification** section: the 109 classified GAP rows, the 80 app lots (33 a / 25 mixed / 22 b) and the features.
- `docs/migration/UX-DECISIONS-PENDING.md` (**new, temporary**): 25 decisions `UXD-01..25`, grouped by screen. Each gives option A (legacy), option B (proposed), a recommendation and its impact on M1–M4. The file is deleted once the decisions are recorded.
- **M5 · UX evolutions as a proposal only**:
  - a ROADMAP row, a README note, the board issue #379 (`status: blocked` until the contributors agree);
  - a `LOTS.md` section with the proposed whole-lot moves and 9 splits (`085b`…`134b`). Its rows do not start with `| LOT-`, so `lots_from_md.py` ignores them. **No lot changes milestone.**
- `LOTS.md` Audit cells: 5 "legacy parity" lots without a source at `2440d79` are relabelled (LOT-100, 101, 146; partly 108 and 127). `tooling/roadmap/lots.json` is regenerated, and only those 5 cells change.
- **H.2 rule**: AGENTS.md §4 adds a paragraph on `// Port of …` comments; `docs/lots/TEMPLATE.md` adds "Legacy counterpart" and "UX evolutions" sections and the App / HFRClient modules. The comments themselves are applied in #378.
- **Specs** LOT-081, 082, 083, 084, 119 and 170: a "UX evolutions (H.1)" section names each (b) item and its UXD id.
- `FEATURES.md`: one paragraph on the classification. Statuses are unchanged.

**Why this wide and no wider:** the directive asks for docs and specs only. No lot moves, nothing is deleted from scope, and no code changes.

**Method.** Four Sonnet agents classified by screen, reading the legacy symbols at `2440d79`. Opus consolidated, checked the disagreements and wrote the docs.
