Not a lot: tracker switch. Refs #166

**Problem.** Issues are enabled on ezzz/HFRnow since 2026-10-27 and #37–#166 were created from the tracker, but the docs still say `docs/LOTS.md` is "the only tracker until Issues are enabled": two trackers would drift.

**Cause.** ADR 0010 made LOTS.md the tracker only while Issues were disabled; the target process (francoisgn/ios-app_SwiftHFR#100) was documented as "later".

**What changed.**
- `docs/LOTS.md` is the plan again: Owner + Status columns → one `Issue` column (#37–#101). Removed, each fact already in its issue (checked against the inventory): "Issues to open" (#102–#108), "Other work" (#142–#144, FEAT #145–#165), "Capture backlog (Mac)" (#109–#141 and #168, one line + `host: mac` search), wave table (#166; the MVP definition stays).
- The claim process becomes current in AGENTS.md (§0 start, §2, §3, §5, §7, §8, §9), ORCHESTRATION (claims, plus "Still manual until the workflows are on `master`": `status: claimed` set by hand, **Issue and claim** not required, issues closed by hand after the merge, no issue forms), CONTRIBUTING, README (docs map, getting started, contributing, agent prompt), CLAUDE.md, the PR template, ROADMAP, ADR 0010 (consequence note) and the ADR 0011 pointer.
- FEATURES.md: Owner column → `Issue` link; the stage column stays.
- Stale "Issues to open" / "until Issues are enabled" references fixed in LOT-024 and LOT-028 specs, research/bybifok-proposals.md, EZZZ-CUTOVER, the `issue-claims.yml` comment.
- Not touched on purpose: the `Issue: none (tracked in LOTS.md)` headers of older lot specs and three Swift comments citing "Issues to open" #1/#6/#7 (in App/ and tests, to avoid conflicts with open lot PRs).

**Tests.** `scripts/check-lot-deps.py` expects 9 cells; new `scripts/tests/test_check_lot_deps.py` (valid plan passes, issue numbers are not read as dependencies, an old 10-cell row fails, forbidden module dependency fails, unknown dependency fails); all 5 fail on the old script. `check-lot-deps.py`: 65 lots, 0 violations; `unittest discover scripts/tests`: 25 OK; markdownlint passes; local links and anchors resolve.
