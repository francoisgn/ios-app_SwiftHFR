### Summary

As a user, I want to pick the look of the app in a gallery of themes — each shown with its colours, its name and its author, grouped by family — so that the app looks the way I like; and as a theme author, I want a theme to be a token file plus optional art, so that adding one needs no code.

- **Engine.** Decode `App/SwiftHFR/Themes/<theme-id>/theme.json` (folder-synchronized, ADR 0012), resolve `light` / `dark` / `any` against the appearance LOT-121 already applies, expose the tokens through the SwiftUI environment and to the reader's CSS variables (the LOT-121/122 path: `--app-*`, #568's derived tokens).
