### Summary

As a user, I want to pick the look of the app in a gallery of themes — each shown with its colours, its name and its author, grouped by family — so that the app looks the way I like; and as a theme author, I want a theme to be a token file plus optional art, so that adding one needs no code.

Operator request of 2026-10-28. M4 (operator 2026-11-07: themes, icons and appearance are all M4).

### Scope

The contract is [`docs/THEMES.md`](https://github.com/ezzz/HFRnow/blob/dev-swift/docs/THEMES.md) §1–§3, §8.

- **Engine.** Decode `App/SwiftHFR/Themes/<theme-id>/theme.json` (folder-synchronized, ADR 0012), resolve `light` / `dark` / `any` against the appearance LOT-121 already applies, expose the tokens through the SwiftUI environment and to the reader's CSS variables (the LOT-121/122 path: `--app-*`, #568's derived tokens). Store the theme id under a new `SettingKey` (`theme_id`, device scope unless ADR 0013 says otherwise); unknown id → Legacy.
- **Legacy theme = today's app.** With Legacy selected every pixel is what LOT-121/122 draw now (hue slider, dark style, brightness, defaults unchanged). The other themes override tokens.
- **Gallery** inside the existing « Thème » screen, below the shipped pickers: families (Classiques, Rétro, OG Web, then seasonal families from LOT-166 inside their window), a light + dark swatch (one swatch and « clair = sombre » for a single-variant theme), name, « par <auteur> », check mark; footer « Envie de proposer un thème ? Les règles sont dans le dépôt : docs/THEMES.md (voir le README). »
- **One structure per appearance** (LOT-122 learnings): a theme change may rebuild the screens it wraps; an appearance flip rebuilds nothing; the shipped Standard path stays pixel-identical to no modifier.
- **Contrast test**: every bundled `theme.json` decoded and checked against THEMES.md §3 ratios; a broken fixture theme makes it fail.
- Consistency with #572 (one row, separator and state-tint definition), #646 (capsule text contrast) and #651 (MP title tones « in every theme », operator 2026-11-08): those definitions read tokens, they are not redefined per theme.

Not here: the accent presets (LOT-180, #420), seasonal behaviour (LOT-166), the themes themselves beyond Legacy (LOT-192, LOT-193, Noël abusé in LOT-166, Samain LOT-191).
