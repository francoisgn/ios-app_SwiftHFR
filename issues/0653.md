### Where this request differs from the legacy code
- **"Cancel".** In the legacy toolbar, the first button is **"Vider le texte"** (clear the text). The **undo** button carries the accessibility label "Annuler" (`AnswerView.swift:504-508`). Closing the composer is the header's `xmark`. This issue reads "cancel, back, forward" as clear, undo, redo, the legacy order. **The operator should confirm.**
- **"Formatting options".** Legacy has no formatting button: it has an edit menu. A "Format" button that opens the bar is new. SwiftHFR already has the bar (LOT-085).
- **"Only send at the top".** Legacy already had the up-arrow send at the top right. It also had a close `xmark` at the top left. Removing close from the top is new: where cancel or close goes must be decided. Swipe-down stays (UXD-15, #429).
