### Summary
As the maintainer, I want the LOT-119 settings screen checked in light mode, dark mode and Dynamic Type XL on the simulator, so that #292 (merged without these checks, by operator decision of 2026-10-29) does not ship a layout we never saw.

### Context
- #292 (LOT-119, closes #210) adds the settings sheet: gear button in the sidebar, sections "Général" (start screen, text size slider 70–130 %, compact mode, tab-bar option, rotation lock, default browser) and "Apparence" (Thème / Icône placeholder rows).
- #210 asks for light, dark and Dynamic Type XL checks. Cloud agents cannot run the simulator, so the PR says "Not done here". CodeRabbit raised it (https://github.com/ezzz/HFRnow/pull/292#discussion_r4408882752). The operator chose to merge first and track the checks here.
- CI covers `App build + tests (iOS 27 simulator)`, which passed on #292's head `a5923eb`. These checks are visual only.

### Scope
On iPhone 18 Pro and iPad Pro 13-inch (M5), iOS 27.0:
1. Open the settings sheet in light mode and in dark mode: legibility, contrast, section headers, slider and pickers.
2. Dynamic Type at XL (and the largest accessibility size if possible): no clipped labels, rows wrap, the slider value stays readable, the "Apparence" rows stay tappable.
3. Rotation lock on iPhone: portrait-only once locked; the iPad always rotates.

### Acceptance criteria
- Screenshots (or a short written report) posted on this issue for each mode and device. No real pseudo or account data visible.
- Any defect becomes a fix PR (`Closes` this issue) or a separate `type: bug` issue linked here.
- Stored-only settings (text size → LOT-169 #295, tab bar → LOT-170 #296, default browser → LOT-137) are not in scope.
