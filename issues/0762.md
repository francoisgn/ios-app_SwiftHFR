## francoisgn · 2026-11-13T13:43:06Z

/claim mac/M1

- The badge reads only the forum list loaded once at launch (`RootModel.unreadPrivateMessages` → `forums.loader.value`), refreshed only by a pull-to-refresh of the Forums tab; legacy rewrites `nb_mp` from every home, favourites and topic-list page it parses (`ObjCForumsParser.m:524`, `ObjCFavoritesLoaderWorker.m:97`, `HFRplusAppDelegate.m:704-706` @ 87fe0d1c). The 2026-11-10 captures parse to 6 everywhere, so the 7 is a stale count.
- Fix: the badge takes the latest count HFR announces on any list page the app loads (home, topic lists, favourites/flags), the newest request winning; a page without the entry keeps it.
- Tests in `RootModelTests` (fail before the fix), gate `f762`; PR opened by mac/M1.
