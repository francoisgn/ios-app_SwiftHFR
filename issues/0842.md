### Summary

As a user who picks a theme, I want list rows, separators, selection and the native title text to follow the theme too, so that strong themes (Rétro 5250, the OG table look) look whole instead of showing system grey rows on a themed background. Follow-up of LOT-188 option (a) (operator, 2026-11-12, #729).

### Context

LOT-188 (#729, PR #829) recolours the screen backgrounds, the tint, the prominent buttons, the unread capsule and the reader. By decision (a), native list rows and cards keep the system raised colour, and native text keeps the system label colours (`docs/THEMES.md`, "What a theme does not change"). Recolouring them needs a `listRowBackground` on each row of every list, which is why this waits for the refactor of #836: done after it, the change goes in the one shared row and list component, not in each copy.

### Scope

No second colour model (LOT-188 spec).
