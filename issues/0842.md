### Summary

As a user who picks a theme, I want list rows, separators, selection and the native title text to follow the theme too, so that strong themes (Rétro 5250, the OG table look) look whole instead of showing system grey rows on a themed background. Follow-up of LOT-188 option (a) (operator, 2026-11-12, #729).

### Context

LOT-188 (#729, PR #829) recolours the screen backgrounds, the tint, the prominent buttons, the unread capsule and the reader. By decision (a), native list rows and cards keep the system raised colour, and native text keeps the system label colours (`docs/THEMES.md`, "What a theme does not change"). Recolouring them needs a `listRowBackground` on each row of every list, which is why this waits for the refactor of #836: done after it, the change goes in the one shared row and list component, not in each copy.

### Decision (operator, 2026-11-18)

Option B: do this now, before the #836 duplicates review. The recolour goes in **one shared view modifier** (e.g. `.themedListRow()`, plus whatever a list itself needs, such as separators, selection and the section header), applied at every existing list call site. The colour rule lives in one place only; #836 later merges the list copies and their call sites, and the modifier comes along. #836 is no longer a blocker; #829 is merged.

No second colour model (LOT-188 spec).
- Legacy is unchanged (pixel tests of LOT-188 stay green).
- Contrast rules of `ThemeDefinitionTests` extended to the new pairs (text on `surfaceRaised`, selection).
- Needed by LOT-192 (#733, Rétro 5250) and LOT-193 (#734, OG clair/gris).

## francoisgn · 2026-11-18T10:58:11Z

**cloud/i842-opus**: one point for the operator on #1118, about which token paints list rows.

The issue lists `surfaceRaised` among the list tokens. The PR paints rows and cards in **`surface`** instead, following THEMES.md §3, the theme contract, which says `surface` is "rows and cards" and `surfaceRaised` is "bars and sheets". The reason is concrete: the bundled Noël abusé has `surfaceRaised` #8E0E24 (red), so using it would paint every list row red.

`surfaceRaised` stays undrawn. Switching is a one-line change in `ThemeAppearance.listColors` plus the contrast rules, if you prefer it.
