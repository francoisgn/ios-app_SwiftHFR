# Issue #570: [SwiftHFR] MP list: tint unread conversations so they stand out

### Summary
As a member scanning my MPs, I want unread conversations to stand out from read ones. Operator feedback after a device test, 2026-11-07, milestone M4:
- the accent dot is visible;
- the semibold title does not set them apart enough;
- a light accent tint on the row background is wanted.

### Current
- `Messages/MessageRowView.swift:16-41` marks an unread conversation with a semibold title and an accent dot labelled "Non lu".
- There is no row background.
- `TopicListView.swift:112` (super favourite) uses `listRowBackground(Color.orange.opacity(0.12))`. That replaces the row's own background instead of layering over it.

### Legacy
`MPListView.swift:406-483` @ 2440d79 shows a semibold title and a grey "non lu" capsule.

### HIG
Do not use colour alone; the dot, the bold title and the "Non lu" label already cover that. No HIG rule forbids a state tint, so the operator's request holds.

### Proposal
- Layer a few percent of the accent over the real row background, using one shared `RowTint` helper.
- Reuse the same helper for the super-favourite row.

```swift
.listRowBackground(isUnread ? RowTint(strength: scheme == .dark ? 0.16 : 0.10, increased: contrast == .increased) : nil)
// RowTint = Color(.secondarySystemGroupedBackground) (or .systemBackground for a plain list) overlaid with accent.opacity(strength [+0.08])
```

Set the list style explicitly so the base colour matches. On iPad, the tint must not hide the selection highlight.

### Acceptance
- A test of the strength rule.
- A Mac check in light, dark, Increase Contrast, iPad selection and Dynamic Type XL.
- A GAP row records the change.
