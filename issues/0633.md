### Summary
As the team, we want a short technical spec of the survey form, so that it is built without back-and-forth.

### Scope
- Stack suited to a small VPS (the sub-domain is chosen later).
- Data model of one answer; theme 2 shown only to iPad, Duo or multi-device profiles.
- Formats: single choice, card sort, reaction cards, free text; every question optional.
- End screen with live statistics; anti-duplicate without account, rate limiting, honeypot; CSV and JSON export.
- Deployment and removal procedure. Code location: `tooling/ux-survey/` on `dev-swift`.

### Deliverable
`docs/ux/questionnaire/formulaire-spec.md`.

### Model and review
Opus author, Fable review. Brief: `docs/ux/cadrage-agents-questionnaire.md` §3, UX-09.

### Before you start
