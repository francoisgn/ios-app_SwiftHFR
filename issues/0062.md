### Summary

As a reader, I want the video links of a message (YouTube, Vimeo, Streamable) detected with the right start time, so that the reader can offer a player instead of a bare link.

### Scope

A pure function in HFRParsing that turns the candidate links of a message body (the LOT-034 `links`, signature excluded) into `MessageContent.embeds` (`MessageEmbed`, `EmbedProvider`, LOT-011). Same host rules as legacy; the YouTube hour bug fixed on purpose; whether a plain `t=<seconds>` gives a start is decided in the spec (audit C09). The parser fills `embeds` whatever the display settings (LOT-034 spec); showing a player is app policy (LOT-108, #199).
