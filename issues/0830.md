### Summary

LOT-057 (#83) reads the logged-in REST flag buckets (`R335a`-`R335c`) into the favourites page model, but the published captures cannot tie a bucket row to the flags page row of the same topic (both are aliased by position), so a REST row opens at its last page instead of where the member stopped, and its read state stays unknown. These read-only captures settle that, and what HFR answers a bucket when the session is missing or stale.

### Captures (read-only GETs, FIXTURES.md rules; compare raw values on the Mac, publish only the aliased files and the comparison's outcome)

1. **Same topics, both sides, one minute apart** (user1): `GET /webservices/rest_api.php?uri=forums/hardwarefr/topics/participated/` and `GET /forum1f.php?owntopic=1`. For each topic in both: does `last_post_read_id` equal the `numreponse` of the row's flag link (`#t<numreponse>`)? How does `last_position` relate to the flag link's `page=` (offset of the last read message, 40 per page)? Is `is_read` true exactly for the rows without a flag image (no news)? Same for `read` against `forum1f.php?config=hfr.inc&owntopic=2&new=0&nojs=0` and `favorites` against `owntopic=3`.
2. **Does a bucket list topics `forum1f.php` drops?** HFR-PROTOCOL §6c: `owntopic=1` on `forum1f.php` shows only the rows with news (run observation). Count the topics of the REST `participated` bucket against `forum1f.php?owntopic=1` and `forum1.php?…&owntopic=1` of one category.
3. **Global bucket completeness**: redface2 E1 says the global bucket is "truncated by recency". For an account with many topics (user1, `read`: 197 entries in one category, `R603f` run observation), does each group's `results_count` equal its number of entries, and the sum equal the flat buckets' (`…/categories/<cat>/topics/read/`) for every category?
4. **No valid session**: the global `participated` bucket without cookies, and with the stale cookies of `R70a`-`R70d` (`md_user`, `md_id`, a wrong `md_passs`): status, `Content-Type`, `Set-Cookie` names, body shape.
5. If `flag_owntopic` = 2 ever shows (redface2 C12 says the red "read" flag), note on which bucket.
