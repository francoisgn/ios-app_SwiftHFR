### Summary
As an iPad or iPhone Pro Max (landscape) user, I want the Messages list to keep its look, because #576's explicit `.listStyle(.insetGrouped)` turned the plain list of the split column into a grey background with an inset card, which its PR said it would not change.

Refs #576 (found in its Mac completion check). Related: #572 (one row and state-tint definition).

### Observed
Same account, same list, same states, side by side: a build of `c62ec7df` (just before #576) against `0822f99b` (with #576); unchanged on `2d851cf2` (current dev-swift). Simulators iOS 27.0, iPad Pro 13-inch (M5) landscape and iPhone 18 Pro Max landscape. Pixel values measured on screenshots.

| Device, mode | Before #576 | After #576 |
|---|---|---|
| iPad, light: column background | 255,255,255 (plain list) | 242,242,247 (`systemGroupedBackground`) |
| iPad, light: read row | 255,255,255 | 255,255,255 on an inset card with rounded corners |
| iPad, dark: read row | 0,0,0 | 28,28,30 (card) |
| iPad, Increase Contrast dark: read row | 0,0,0 | 36,36,38 |
| Pro Max landscape, light: read row | 255,255,255 | 240,240,240 (card over the white column) |
| Pro Max landscape, dark: read row | 57,62,63 | 72,77,78 |
| iPhone 18 Pro portrait (compact) | grouped card | unchanged (242,242,247 around a white card) |

In regular width the automatic style of the column was the plain list; the explicit `.insetGrouped` (`MessageListView.swift`, "explicit: the row tint's base colour is the grouped one") replaced it. The Favoris list, left on the automatic style, is unchanged (pixel diff below 0.2 %, clock only).

### Expected
The Messages list keeps the pre-#576 look in every width, and the unread tint sits on the colour actually under the row: `.grouped` base in compact width, the plain or column base in regular width (like `TopicListView.tintBase`).

### Acceptance criteria
- iPad and Pro Max landscape: same column and row colours as before #576 in light, dark and Increase Contrast; the unread tint still shows and the selected row still shows the system highlight.
- iPhone portrait unchanged.
