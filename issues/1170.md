### Summary

As a reader using a large text size, I want the message « + » button to grow with the text next to it, so that the entry to every message action stays easy to see.

### Rule

"Increase the size of meaningful interface icons as font size increases. If you use interface icons to communicate important information, make sure they're easy to view at larger font sizes too." — [HIG › Typography](https://developer.apple.com/design/human-interface-guidelines/typography) (Supporting Dynamic Type; page updated 2025-12-16).

### What the app does (dev-swift @ `7a61018f`)

`App/SwiftHFR/Reader/Resources/reader.css:217-221`: `.message button.menu-button { … width: 44px; height: 44px; … }` and `.message button.menu-button svg { display: block; width: 16px; height: 16px; }`; the comment (`:213-216`) says "in px so neither the font nor the reader's text size changes it, as in legacy". The rest of the page follows Dynamic Type (`font: -apple-system-body`). The 44 px tap box and the `aria-label` are fine.
