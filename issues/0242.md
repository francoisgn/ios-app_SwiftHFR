## francoisgn · 2026-11-02T19:11:26Z

Requirement from ADR 0014 §4 (#442, LOT-097): the preview render is not linear on two shapes HFR accepts (repeated crossed tags, deeply nested `[quote]`/`[spoiler]`; measurements on #445), and a SwiftSoup parse cannot be cancelled. LOT-152 therefore calls `BBCodeRenderer.render` off the main actor, debounced, and **skips the live preview above a nesting depth or size it sets** (an on-demand preview stays possible). The smiley table is built once into `BBCodeRenderOptions` (assigning it code by code rebuilds the prepared table each time). Whether the app previews locally, through `/apercu.php`, or both is the operator's choice O-1 on #189.
