### Summary

As a user with several accounts, I want the account menu to mark the current account with the system selection checkmark, with every row aligned, so that the menu reads as a standard choice list.

### Rule

"Apply a uniform visual treatment across menu items in the same group. For visual consistency and balance, provide icons for all menu items in a group, or none of them." and "Consider using a checkmark to show that an attribute is currently in effect." — [HIG › Menus](https://developer.apple.com/design/human-interface-guidelines/menus) (Icons, Toggled items; page updated 2026-06-08).

### What the app does (dev-swift @ `7a61018f`)

`App/SwiftHFR/Accounts/AccountMenuButton.swift:34-38`: `if row.isMain { Label(row.displayName, systemImage: "checkmark") } else { Text(row.displayName) }`: the selected state is drawn as the item's icon, so one row of the group has an icon and the others have none.

### Legacy at `87fe0d1c`

`HFRswift/Swift/AccountMenuViews.swift:15-25`: every row is a `Label` with the avatar as icon and the checkmark after the name: uniform. SwiftHFR is worse.
