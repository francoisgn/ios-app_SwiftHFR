### Summary

As the operator, I want every SwiftHFR issue to say where its work comes from (audit, initial port, parity gap, deliberate difference, feedback on the Swift app, legacy evolution, infra), so that the work can be counted and steered by origin. Operator decision of 2026-11-09.

### Scope

1. **Axis** (PR): seven `origin:` labels in `.github/labels.yml`, an "Origin" row in the AGENTS.md §7 axis table (one label per axis now includes origin), the issue forms and `issue-triage.yml` map an Origin answer. The labels are created on GitHub now (the sync workflow runs only from `master`).
2. **Backfill**: every SwiftHFR issue of ezzz/HFRnow, open and closed, gets exactly one `origin:` label, from a deterministic, reviewable mapping (rules first, then a judged pass on every low-confidence row). Legacy-app issues (`[Legacy …]`) get none. The frozen mirror `francoisgn/ios-app_SwiftHFR` is out of scope.
3. **Independent check** of the mapping by a different model before it is applied.

| Label | Meaning |
|---|---|
| `origin: audit` | Came out of the LOT-000 audit or its review (`docs/audit/`) |
| `origin: initial-port` | The initial migration plan: planned port lots, their fixtures, captures and follow-ups |
| `origin: parity` | A parity gap with legacy found later (H.1 (a) rows, UXD (a) items, parity checks) |
| `origin: deliberate-gap` | A deliberate difference: (b) items, UXD evolutions, FEAT, M5, operator design choices |
| `origin: swift-feedback` | Found by testing SwiftHFR: device tests, beta testers, Mac checks, Bybifok on SwiftHFR |
| `origin: legacy-evolution` | Backport of a legacy change after `2440d79` (the `2fe43da3` sweep of #655) |
| `origin: infra` | Repo, CI, tooling, process, orchestration or docs upkeep not tied to another origin |

### Acceptance criteria

- [ ] The axis PR is merged; AGENTS.md §7 lists the Origin axis.
- [ ] The mapping is reviewed by a different model, then applied: every SwiftHFR issue carries exactly one `origin:` label.
- [ ] `beta-test finding` and `moust4ki aka bybifok finding` stay where they are.
