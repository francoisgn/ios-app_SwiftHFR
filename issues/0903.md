### Scope

1. **Section Réglages › Expérimental**, at the end of the Réglages list, with one footer sentence: "Options en cours de mise au point, désactivées par défaut." It is organised in **sub-menus by theme** (operator, 2026-11-14), for example Composer, Listes, Messages, Chargement des images. Each row is a switch or a picker, with an ⓘ that explains what it changes.
2. **One entry point in the code**:
   - an `ExperimentalFeature` enum (one case per option) and an `ExperimentalSettings` store with one device-level key per option, all default `false`;
   - the new keys are added to the ADR 0013 storage matrix (Device-only);
   - views and models read a flag through that store, never a raw `UserDefaults` key.
3. **Code isolation**:
   - each option's code moves to `App/SwiftHFR/Experimental/<Option>/`;
   - every place where an option replaces, wraps or disables code carries one marker comment, `// EXPERIMENTAL(<option>, #<issue>): replaces <view or behaviour>`, so `git grep "EXPERIMENTAL("` lists them all;
   - removing an option means deleting its folder, its enum case and its markers.
4. **Options at the start** (the modern code moves behind its switch in this PR; nothing is rewritten):

| Option (enum case) | Switch label | On (experimental) | Off (default) | Issue |
|---|---|---|---|---|
| `modernComposer` | Composer moderne | today's compact composer card (#888) and its follow-ups #853 and #895 | the legacy full-screen composer, delivered by #855. **Until #855 merges, this PR keeps the switch ON by default** so the app is never left without a composer; #855 flips the default to off. | #904 |
| `searchTab` | Recherche dans la barre | a 5-item tab bar with Recherche left of Plus | the 4-item legacy bar | #896 |

| `imageLoadingChoice` | Chargement des images (sub-menu) | the Jamais / Wi-Fi uniquement / Toujours picker | always load, as legacy | #902 |

   `searchTab`, the #859 switches and `imageLoadingChoice` are not built yet: this PR only adds their enum cases and rows, hidden until their PR lands (no dead switch).

   - hide the "save this page offline" entry and every offline button or menu item;
