### Summary

As a user adjusting Réglages, I want the sliders (« Taille du texte », the accent hue, the dark-theme brightness) to follow my finger smoothly, so that I can see the result while I drag. Today they feel extremely slow, as if every movement redraws too much. (Operator feedback, 2026-11-18, on the current build.)

### Today (dev-swift), what each tick does

- **Accent hue**: `Slider(value: $theme.accentHue, in: 0...1, step: 0.001)` (`App/SwiftHFR/Settings/ThemeSettingsView.swift:60`), so up to 1,000 steps. Every change runs `ThemeSettingsModel.accentHue.didSet` (`ThemeSettingsModel.swift:51-60`): it recomputes both accents and **writes two settings to the store** (`dayActionColor`, `nightActionColor`).
- **Dark brightness**: `step: 0.01` (`ThemeSettingsView.swift:74`). Each change writes `nightBrightness` to the store (`ThemeSettingsModel.swift:63-69`).
- **Text size**: each step writes `textSizePercent` (`SettingsView.swift:94-104`).
- Each write likely re-renders the whole app tree. The theme feeds the app root: accent, `ThemeAppearance`, the reader variables injected into every open `WKWebView`, the settings preview and the gallery. Synced keys may also go to iCloud KVS on every tick (ADR 0013 scopes). Measure this, do not assume it (AGENTS §3 rule 9).

### Scope

1. **Measure first**: Instruments (Time Profiler, SwiftUI) on the simulator or a device, dragging each slider for 3 s. Name the hot path in the PR, with numbers: store writes, KVS pushes, root body re-evaluations, web view script injections.
2. **Fix the cause** while keeping the live preview:
   - the slider drives a **local draft value**, and the screen and the settings preview follow it live;
   - the **store write**, and any iCloud push and reader re-injection, happen once on release (`onEditingChanged` false), or coalesced (e.g. at most every 150 ms while dragging), whichever the measurement favours;
   - the hue step can be coarser if 1,000 steps add nothing visible (state the choice).
3. Behaviour is unchanged: the final value is saved exactly once. VoiceOver adjustments (increment and decrement) still save each step. Open readers update after the release.
4. Check the other sliders and steppers of Réglages for the same pattern.
