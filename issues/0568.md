# Issue #568: [SwiftHFR] Reader: separate messages visually (alternating tint and stronger separator)

- State: closed

- Labels: type: bug, priority: medium, difficulty: easy, area: app, host: mac, beta-test finding

### Summary
As a reader of a topic or an MP, I want each message clearly delimited from the next, so that I see where a message ends without looking for the avatar and signature lines. Operator feedback after a device test, 2026-11-07, milestone M4.

### Current
- `App/SwiftHFR/Reader/Resources/reader.css:49`: the only boundary between messages is `border-bottom: 1px solid var(--separator)`.
  - Light: #d1d1d6 on #fff, contrast ≈1.5:1.
  - Dark: #38383a on #000, contrast ≈1.8:1.
- The modern header tint is 3% of the accent (`:58-59`), almost invisible.

### Legacy
`style-liste-light.css:153-160` @ 2440d79 draws a near-black 1 px rule (`#202020`) above each message, plus a 38 px header band. The dark and OLED sheets use grey borders. The port weakened this without a GAP row.

### HIG
- Alternating colours are mentioned only for macOS multicolumn tables. iOS neither recommends nor forbids them.
- Colours must work in light, dark and Increase Contrast (Color, Accessibility pages).

### Proposal (operator's idea)
CSS only, derived from the theme tokens, so it follows light, dark, the dark brightness slider, a future OLED theme and the classic style:

```css
:root { --alt-strength: 5%; --separator-strong: #c6c6c8;
        --surface-alt: color-mix(in srgb, var(--text) var(--alt-strength), var(--background)); }
/* dark */ --alt-strength: 9%; --separator-strong: var(--app-dark-separator, #545458);
@media (prefers-contrast: more) { /* 10% light, 16% dark */ }
.message { padding: 1em 1em .85em; border-bottom: 1px solid var(--separator-strong); }
article.message:nth-of-type(even) { background: var(--surface-alt); }
:where(article.message:nth-of-type(even)) :is(table.citation, table.oldcitation, table.quote, table.code, table.fixed) { background: var(--placeholder); }
```

- `nth-of-type` ignores `div.separator1`.
- Header, `.me` and whitelist tints compose on top.
- Check text contrast: `--secondary` on the alternate surface is ≈4.7:1 in light.

### Acceptance
- A web test (`ReaderInsetsWebTests`-style) reads `getComputedStyle` on articles 1 and 2, in light and dark.
- A GAP row records the divergence.
- Mac check: light, dark (brightness 0–150 %), classic, Increase Contrast, Dynamic Type XL, topics and MPs.
- Coordinate the token values with LOT-122 (#213).
