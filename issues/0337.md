### Summary

As the maintainer back on the Mac after the quota reset, I want **one ordered list of the captures to make**, each showing the lots it blocks and what it unblocks next, so that every capture session frees the most work.

This issue is the **Mac capture backlog**. Each capture issue is a sub-issue of it. The restart plan on #166 (step 2) points here. Boards: #166 (M1) and #324 (M2 to M4).

### How to work it

- One capture session at a time, on the Mac CLI, with the LOT-001 kit (`tooling/fixtures/`). Follow FIXTURES.md: anonymize, check independently before pushing (LESSONS 33-34), add a legacy oracle when a parser consumes the page.
- ✍️ = the capture sends a **write** to the forum (post, vote, alert, delete, flag, upload). It needs the operator's approval first (AGENTS.md §0). Use the operator's own accounts only.
- When a capture PR merges:
  - close the capture issue with `Done in #PR (merged as <sha>)`;
  - run the unblock procedure (ORCHESTRATION.md): relabel the lot `status: ready`, comment `Unblocked by #PR`, update the boards;
  - tick the row here.
