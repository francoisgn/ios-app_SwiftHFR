### Summary

As a user long-pressing a favourite, I want the context menu to list only what I can do now, as the HIG asks for context menus, so that the menu is not padded with dimmed entries.

### Rule

"Hide unavailable menu items, don't dim them. Unlike a regular menu, which helps people discover actions they can perform even when the action isn't available, a context menu displays only the actions that are relevant to the currently selected view or content." — [HIG › Context menus](https://developer.apple.com/design/human-interface-guidelines/context-menus) (Best practices; page updated 2023-12-05).
