Reply, quote, edit, delete, flags and reload have no second implementation. Two differences only: `showLatestPost` for `cat=prive` (`TopicReaderModel.swift:393-400`, justified by a missing capture) and #1189. So #908's cause is not a separate MP path in the code at `7a61018f`.
