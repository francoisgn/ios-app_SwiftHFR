Plan:
- Cause (from the code, device check pending on #893): `ScreenTitleModifier` combines `.toolbar(removing: .title)` with a `.principal` item whose content is an `if` that is empty until the pill is due. The system drops the empty/removed title slot and never re-creates it, so even `.pill` screens (always true) show nothing.
- Fix: drop `toolbar(removing: .title)`; the `.principal` item always carries the pill, hidden (opacity 0, no hits, not in VoiceOver) while the large title is on screen. The slot stays occupied, so the system inline title does not come back either.
- Pure rule `ScreenTitleStyle.pillPresentation(headerVisible:)` (`.shown` / `.reserved`, never absent), tested with Swift Testing.
- Recherche: `ScreenLargeTitle` as first row + `.largeThenPill`; the category list keeps `.pill` with its name.
- GAP-978 `gap-edit` in `### Ledger`. Draft PR with `compile-check`, Opus review.
