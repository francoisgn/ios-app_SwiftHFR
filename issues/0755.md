### Summary
As a reader, I want a message's signature to be set apart by one thin line across the width of the message, not by the row of dashes « --------------- » HFR prints before it, so that the page reads cleanly (operator device feedback, 2026-11-10, after signatures showed again).

### Facts
- On the device, with « Afficher les signatures » on, each signature is preceded by a row of dashes on the same line (« ——————… »).
- Legacy removes HFR's 15-dash string from the message before rendering: `HFRswift/Wrapped/LinkItem.m:74` @ `87fe0d1c`, `stringByReplacingOccurrencesOfString:@"---------------" withString:@""`. It removes every occurrence, not only the one before the signature.
- SwiftHFR does not port it yet: LOT-034 left it out until a capture shows the exact markup (#267, `host: mac`). The committed captures anonymize signatures to « Signature removed. », so none shows the separator.
- `App/SwiftHFR/Reader/Resources/reader.css:133` already draws `border-top: 1px dashed` above `.signature`. The dashes text and that border add up.
