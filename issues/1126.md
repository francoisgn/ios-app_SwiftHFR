### Summary

As a writer, I want every button of the composer to share one shape and one size, so that the composer reads as one coherent tool. Today the top buttons (close `xmark`, drafts `tray`, send `arrow.up`) are smaller glass circles with a bold glyph, while the tools in the card (clear, undo, redo, smileys, GIF, image, `Aa`) are larger round chips with a medium glyph. **The tools in the card are the target** (operator feedback, 2026-11-18, device screenshot: the top buttons circled in yellow, the card tools in blue).

### Today (dev-swift)

| | Top buttons (yellow) | Card tools (blue, the target) |
|---|---|---|
| Code | `ComposerHeader.swift:114-155` | `ComposerControlRow.swift:95-125` |
| Shape | `.buttonStyle(.glass)` / `.glassProminent`, `.buttonBorderShape(.circle)` | `Circle().fill(.quaternary)` chip (`ComposerToolStyle.chipDiameter(cell:)`), `.plain` |
| Size | 18 pt frame + 8 pt padding = 34 pt circle | cell `max(metrics.cellSize, ComposerHeader.hitSize)` (≥ 44 pt hit area), chip diameter from the cell |
| Glyph | `.system(size: 14–16, weight: .bold / .semibold)` | `.system(size: metrics.glyphSize, weight: .medium)`, density, Dynamic Type and text scale aware (#598) |

The round chips are the `pills` tool style of the modern composer (`EXPERIMENTAL(modernComposer, #904)`, #895 D).

### Scope

1. The close, drafts and send buttons take the card tools' **diameter, glyph size and weight, and metrics**. Use one shared definition, not a copy: extract the chip and cell sizing so both rows call it.
2. **Operator decision (2026-11-18): only shape and size change.** The top buttons keep their glass background (`.glass`, and `.glassProminent` for send with something to send and drafts with drafts), since they float over the page. The greyed state and the spinner also stay. Only the circle's diameter and the glyph size and weight align with the card tools.
3. The top buttons follow `ComposerToolStyle`: with the `pills` style they match the chips; with the other style they match that style's cells. One rule for both rows.
4. Every composer presentation: iPhone partial height and full screen, iPad sheet, and the legacy composer if it shows these buttons. Light and dark, and Dynamic Type XL.

### Acceptance criteria

- [ ] The state tests (send greyed, prominent, spinner; drafts tinted) still pass.
- [ ] Before/after screenshots in the PR (iPhone partial height, dark), plus a device check on the next general review (#893).
