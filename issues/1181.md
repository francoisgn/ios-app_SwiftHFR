### Summary

As an iPhone user with a large text size, I want the explanation behind a Réglages ⓘ button to be fully readable, so that a long explanation is not clipped inside a small popover.

### Rule

"Avoid displaying popovers in compact views. Make your app or game dynamically adjust its layout based on the size class of the content area. Reserve popovers for wide views; for compact views, use all available screen space by presenting information in a full-screen modal view like a sheet instead." — [HIG › Popovers](https://developer.apple.com/design/human-interface-guidelines/popovers) (iOS, iPadOS).

### What the app does (dev-swift @ `7a61018f`)

- `App/SwiftHFR/Settings/InfoBubbleButton.swift:15-16`: `.popover(isPresented: $isShown) { bubble().presentationCompactAdaptation(.popover) }`.
- Used by four rows: `Settings/ReplyButtonRow.swift:17`, `Settings/DefaultBrowserRow.swift:11`, `Settings/SecuritySettingsSections.swift:19`, `Settings/FilterMinimumQuotesRow.swift:14`.
- The content is several sentences with `.fixedSize(horizontal: false, vertical: true)` and no `ScrollView` (`Settings/ReplyButtonInfoView.swift:7-18`: three titled paragraphs).
