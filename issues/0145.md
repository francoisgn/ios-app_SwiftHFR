Operator decision 2026-10-28 (navigation): preserve what works. The legacy bottom bar "Catégories / Favoris / Messages / Plus" stays (LOT-170 (#296)); **Drapeaux / Favoris do not go on top of the home page**, and the Home "À suivre" does **not** replace the Favoris tab by default. This feature may come later as a community proposal *if the community supports it*: until then it stays `proposed`, and if it is built it is opt-in only (start-screen choice), never the default and never above the Catégories list.

Acceptance criteria added here (FEAT-001, LOT-143 (#233), LOT-144 (#234)):
- [ ] Community support recorded on this issue (link to the forum discussion) before LOT-143 is claimed.
- [ ] Default navigation unchanged: the app still opens on the legacy tabs, Favoris tab unchanged; Home is reachable only when the user chooses it.
- [ ] On iPad, Home is not inserted above Catégories in the sidebar by default.
