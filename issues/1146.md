### Summary
As the app, I need to know what HFR answers for a category topic list requested past its last page, so that the « page x / y » menu's typed page (#980) can be bounded or handled without a guess.

### Why
#980 lets the user type a page in the « page x / y » menu. While the page count is only a lower bound (HFR's pager is a window), the typed page is sent as typed, like the MP list (#968). What HFR answers for a category list page past its end is not captured (R24 covers topics only): it may redirect to the last page, answer an empty list, or something else. A typo such as 9999 could otherwise show « page 9999 / 9999+ » over an empty list.

- a category list page far past the last page (`liste_sujet-<N>.htm`, N well above the last), logged in and logged out;
- the same for a sub-forum list;
- note the HTTP status, redirect chain and the pager shown.
