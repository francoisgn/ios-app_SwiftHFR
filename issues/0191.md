Legacy's `canCreatePoll` requires `have_sondage` (`HFRswift/Swift/ReplyService.swift:279-281` @ `87fe0d1c`), so at the reference it never offers a poll on a new topic. The lot should load `nouveau_sondage.htm` when the user asks for a poll, rather than look for the checkbox. What `bddpost.php` answers to a poll post is still not captured (a public write).
