### Scope

1. **Low.** While a poll is set, the composer shows `ComposerMessages.pollUnsupportedForm` for **every** `.unsupportedForm` (`ReplyComposerModel.send()`), including one that does not come from the poll check: an edit form of another message, a control `PostingBody` refuses. Fix: add a dedicated `PostingError` case for the poll-field check of `PostingFlow.pollFields`, match only that case, and test that a non-poll `unsupportedForm` with a poll set keeps the generic sentence.

3. **Detail.** `PollCreationTests.dateFields` checks the hour in Europe/Paris, so on a machine in that zone it cannot tell `device.timeZone` from `.current`. Use a zone build machines are unlikely to run in.
4. **Detail.** `ReplyComposerModel`'s body is at 248 of the 250 lines `type_body_length` allows. Extract something before the next addition.
