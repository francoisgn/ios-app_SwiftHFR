### Operator decisions (2026-11-15, device screenshot of the topic reader)

These replace two rows of the Scope above.

1. **Page bubble « current / total » (e.g. « 20878 / 20878 »):** keep it, but **hidden while reading**. It appears with a short animation only when the end of the page is reached, and hides again when scrolling back up. This replaces "remove the page button". VoiceOver keeps the page actions reachable at all times.
2. **Refresh at the bottom: the same button, reused.** At the end of the page, the **same refresh control as the top bar's** (one component, one action) also shows in the bottom bar, next to the bubble and the reply button. The top-bar refresh **stays**, which replaces "no refresh in the top bar". The legacy end-of-last-page highlight still applies to the bottom one.
3. **Tighter spacing above the bottom bar.** The gap between the end of the last message and the bottom buttons is too large. It reads as unused space, like the margin around the floating composer. Use the system's standard spacing above a floating bar, while keeping the last line readable and tappable above the controls (the insets of #852/#878).
4. **Pull up past the end to refresh.** At the bottom of the page, pulling further up (an overscroll at the bottom) triggers the refresh.
   - Show a discreet hint below the last message, almost tone on tone (secondary label, small): « Tirer vers le haut pour actualiser ».
   - Release past the threshold: a short haptic, then refresh, keeping the reading position. Releasing earlier does nothing.

This applies to the MP reader too: both readers share the same bars (per the 2026-11-13 comment above).

### Acceptance criteria (added)
- [ ] Mid-page, no page bubble. At the end of the page, the bubble and the bottom refresh appear together; scrolling up hides them.
- [ ] The bottom refresh and the top refresh run the same action, with the same code path.
- [ ] The gap between the last message and the bottom bar is the standard spacing. Measure it, and put before/after screenshots (redacted) on the PR.
- [ ] Pull-up-at-end: the hint shows, the refresh fires past the threshold with a haptic, and the reading position is kept.
