### Legend

| Column | Emoji | Meaning |
|---|---|---|
| 🔜 Todo | 🟦 ready | `status: ready`: every dependency merged, inputs available, nobody claimed it. Claim it with `/claim <id>`. |
| | ⏸️ M5 not opened | An M5 lot whose dependencies are merged. M5 opens by the orchestrator's decision: do not set `status: ready`. |
| | ⛔ waits on … | Dependencies not merged yet (lot numbers listed). |
| | 📸 waits on capture | Every dependency is merged, but a capture (issue linked, `host: mac`) must land first. |
| | 🟨 triage | Every listed dependency is merged but the issue is still `status: blocked`: either a pending capture blocks it (say which on the issue) or it is ready. |
| 🔄 Ongoing | 🙋 claimed | Claimed, no PR yet (spec, fixtures, code). |
| | 🛠️ draft | PR open as draft (CI or self-review not done). |
| | 🔍 review wanted | CI green, waiting for the adversarial review of the named model. |
| | 🔁 changes requested | Review asked for changes; the author is fixing. |
| | 🟢 approved | APPROVE on the head, CI green: waiting for the merge. |
| ✅ Done | ✅ merged | PR merged into `dev-swift`, issue closed with `Done in #PR (merged as <sha>)`, docs up to date. |

**Flavors of a todo lot:**
- 🍎 Mac: app lot, needs Xcode on the maintainer's Mac.
- ☁️ cloud: engine lot, any cloud session with `swift test`.
- 🤝 external: open to contributors' agents (`external: ready`).
- 💡 FEAT-xxx: a feature proposal (credit in [FEATURES.md](https://github.com/ezzz/HFRnow/blob/dev-swift/docs/FEATURES.md)).
- 🔥 high: high priority.

**Routing** is author → reviewer ([AGENTS.md §6](https://github.com/ezzz/HFRnow/blob/dev-swift/AGENTS.md#6-model-routing-which-agent-does-what)): the reviewer is never the author model.

### Definition of done (every lot)

A lot is ✅ only when all of these hold:
1. Its issue's **acceptance criteria** are met. They are that lot's own definition of done: open the issue linked in its row.
2. [AGENTS.md §9](https://github.com/ezzz/HFRnow/blob/dev-swift/AGENTS.md#9-definition-of-done):
   - the code is in the right module;
   - tests exist (differential tests for ported logic);
   - CI is green;
   - the spec, `HFR-PROTOCOL.md`, ADR and `CHANGELOG-LEGACY.md` are updated;
   - the adversarial review was done by another model;
   - the self-review against LESSONS was done.
3. The PR is merged, and the issue is closed with `Done in #PR (merged as <sha>)`.

A lot is ✅ only when all of these hold:
1. Its issue's **acceptance criteria** are met. They are that lot's own definition of done: open the issue linked in its row.
2. [AGENTS.md §9](https://github.com/ezzz/HFRnow/blob/dev-swift/AGENTS.md#9-definition-of-done):
   - the code is in the right module;
   - tests exist (differential tests for ported logic);
   - CI is green;
   - the spec, `HFR-PROTOCOL.md`, ADR and `CHANGELOG-LEGACY.md` are updated;
   - the adversarial review was done by another model;
   - the self-review against LESSONS was done.
3. The PR is merged, and the issue is closed with `Done in #PR (merged as <sha>)`.
