### Definition (to record as a GAP row or a note in `docs/ARCHITECTURE.md`, not a new document)
**Native lists**: Catégories, topic lists, favourites, MPs, search, filtered posts, offline, accounts, profile.
- Use one explicit `List` style (inset-grouped), with system separators and system background colours.

**Reader**: one token set (`--surface-alt`, `--separator-strong`, `--alt-strength`) derived from `--text` and `--background`, so light, dark, OLED, classic and the dark-brightness slider all inherit it.
