### Summary
LOT-102 (#470) adds image upload to the composer, but no build gives the app a rehost API key yet, so uploading stays off. The key has to reach the build the way ADR 0007 says: a git-ignored `.xcconfig` for local builds, a GitHub Actions secret for CI and release, read through `Info.plist`, and never committed.

### Scope
- Add the git-ignored `.xcconfig` entry and the `Info.plist` key that the LOT-102 code reads. Check #470 for the exact name.
- Add the CI and release secret, which the maintainer sets.
- On the Mac, check that an upload works, and that a build with no key hides the upload button instead of failing.
