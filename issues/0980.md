### Summary
As a reader browsing a category, I want the page controls to appear when I reach the end of the topic list, as « ‹ » and « › » pills with a « page x / y » pill whose menu goes to the first, previous, next or last page or to a typed page, so that I change page where I finish reading, like in legacy and like the MP list (#968).

### Operator feedback (2026-11-16)
1. « Liste des topics d'une catégorie, on fait comme la liste des MP : quand on a scrollé jusqu'en bas on affiche les puces page ‹ ou ›. » Screenshot of the legacy bar « |‹ ‹ 1/500 › ›| » at the end of a category list (not attached: it shows member pseudos).
2. Correction, same day: « Non, appui long ne donne pas last ou first. À gauche des puces flèche on fait une puce page x / y, ici et dans les MP. L'appui sur la puce page x / y permet de choisir première, dernière, précédente, suivante, ou saisie de la page où aller. On reste sur la limite du nombre de sujets / MP affichés dans l'app legacy. »

### Legacy counterpart (@ `87fe0d1c`)
- `HFRswift/Swift/MainWindow.swift:1014-1070` `ForumTopicsPaginationBar`: first (`backward.end`), previous (`chevron.left`), « page / last » button opening the page picker, next (`chevron.right`), last (`forward.end`); each arrow disabled at the first/last page.
- `HFRswift/Swift/MainWindow.swift:775-787`: the bar is the **last row of the list** (so visible only at the end), shown only when there is more than one page (`:407-409` `shouldShowPagination`); the « x / y » button opens `TopicPagePickerSheet` (`:923-930`).
- One HFR page per screen: the list size stays legacy's (no merging of pages).

### Scope
Same pager component as the MP list (#968, decision of 2026-11-16 second comment):
1. Shown only when the list reaches its end (the #898 rule, PR #952 `PagerVisibility`), placed above the Liquid Glass tab bar, never under it. Hidden when the category has one page.
2. Layout, left to right: a pill « page x / y », then the « ‹ » and « › » pills. Arrow pills without a solid fill; the arrow carries the accent colour, greyed on the first / last page (#965 rule).
3. Tap on « page x / y » opens a menu: Première page, Précédente, Suivante, Dernière page, Aller à la page… (page entry as legacy `TopicPagePickerSheet`). Entries that cannot apply are disabled.
4. **No long press** on the arrows.
5. One HFR page per screen (legacy size).

### Acceptance criteria
- [ ] Category list page 1 of N: no pager until the end of the list; at the end, « page 1 / N », « ‹ » greyed, « › » accent.
- [ ] The « page x / y » menu reaches page 1, x−1, x+1, N and a typed page; disabled entries at the bounds.
- [ ] The MP list (#968) and the category list use the same component.
- [ ] Unit tests of the menu targets and of the disabled states at the bounds.
